## Sobre o projeto

Landing page única em HTML + CSS + JS puro. Sem build, sem dependências, sem framework.
Arquitetura mobile-first, foco em performance e experiência editorial.

### Estrutura

- `index.html` — site completo (CSS e JS embutidos)
- `.gitignore` — arquivos ignorados pelo Git

### Seções

1. **Hero** — fundo petróleo com logo e statement
2. **Nossa Visão** — manifesto curto
3. **O Lugar** — cartão da loja + galeria editorial
4. **Planos e Serviços** — 4 cards de combos + lista de avulsos
5. **A Ocasião (Noivas)** — modo noite, território de SPA de noivas
6. **Quem Cuida** — apresentação do time
7. **Curadoria** — placeholder para produtos (fase 2)
8. **Rodapé** — cartão compacto com contato e newsletter

